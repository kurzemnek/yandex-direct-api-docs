# get
  * [Restrictions](https://yandex.com/dev/direct/doc/en/ads/en/ads/get#restrictions)
  * [Request](https://yandex.com/dev/direct/doc/en/ads/en/ads/get#input)
  * [Response](https://yandex.com/dev/direct/doc/en/ads/en/ads/get#output)


Returns parameters of ads that match the specified criteria.
###  [](https://yandex.com/dev/direct/doc/en/ads/en/ads/get#see-also)Learn more
  * [How the "get" method works](https://yandex.com/dev/direct/doc/dg/best-practice/get.html)


##  [](https://yandex.com/dev/direct/doc/en/ads/en/ads/get#restrictions)Restrictions
To manage product ads, use the URL: `https://api.direct.yandex.com/v501/`.
Copied
The method returns a maximum of 10,000 objects.

**AdsSelectionCriteria structure**  
`Ids` |  array of long |  Selects ads with the specified IDs. From 1 to 10,000 items in the array. |  At least one of the parameters: `CampaignIds`, `AdGroupIds`, or `Ids` (or all may be present)  
`AdGroupIds` |  array of long |  Selects ads from the specified groups. From 1 to `adgroup-ids-select` items in the array. |   
`CampaignIds` |  array of long |  Selects ads from the specified campaigns. From 1 to 10 items in the array. |   
`States` |  array of AdStateSelectionEnum |  Selects ads based on the specified states. See [Ad status and state](https://yandex.com/dev/direct/doc/dg/objects/ad.html#status). |  No  
`Statuses` |  array of AdStatusSelectionEnum |  Selects ads based on the specified statuses. See [Ad status and state](https://yandex.com/dev/direct/doc/dg/objects/ad.html#status). |  No  
`Types` |  array of AdTypeEnum |  Selects ads based on the specified types. See [Ad type](https://yandex.com/dev/direct/doc/dg/objects/ad.html#types). Note Filtering ads by subtype is not supported. When the IMAGE_AD value is specified, image ads are returned regardless of the subtype. |  No  
`Mobile` |  YesNoEnum |  Selects ads based on whether the ad is a mobile ad:
  * YES — Mobile ads.
  * NO — Regular ads.

If the YES value is set, only Text & Image ads are received. Don't set this value if you need to get other types of ads. |  No  
`VCardIds` |  array of long |  Selects ads with the specified vCards. From 1 to 50 items in the array. If this parameter is set, only Text & Image ads and dynamic ads will be returned. Don't set it if you need to get other types of ads. |  No  
`SitelinkSetIds` |  array of long |  Selects ads with the specified sets of sitelinks. From 1 to 50 items in the array. If this parameter is set, only Text & Image ads and dynamic ads will be returned. Don't set it if you need to get other types of ads. |  No  
`AdImageHashes` |  array of string |  Selects ads with the specified images. From 1 to 50 items in the array. |  No  
`VCardModerationStatuses` |  array of ExtensionStatusSelectionEnum |  Selects ads based on results of vCard review. For a description of the statuses, see the section [Ad extensions](https://yandex.com/dev/direct/doc/dg/objects/ad.html#addons). `SitelinksModerationStatuses` |  array of ExtensionStatusSelectionEnum |  Selects ads based on results of sitelink review: For a description of the statuses, see the section [Ad extensions](https://yandex.com/dev/direct/doc/dg/objects/ad.html#addons). `AdImageModerationStatuses` |  array of ExtensionStatusSelectionEnum |  Selects ads based on results of image review. For a description of the statuses, see the section [Ad extensions](https://yandex.com/dev/direct/doc/dg/objects/ad.html#addons). If this parameter is set, only Text & Image ads, dynamic ads, and ads for mobile apps will be returned. Don't set it if you need to get other types of ads. |  No  
`AdExtensionIds` |  array of long |  Selects ads with the specified extensions. From 1 to 50 items in the array. If this parameter is set, only Text & Image ads and dynamic ads will be returned. Don't set it if you need to get other types of ads. |  No
