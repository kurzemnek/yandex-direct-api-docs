Types of strategies
# Types of strategies
**Strategy type** |  **Name**  
---|---  
AVERAGE_CPA |  "Optimize conversions", maintain the average CPA See the [description](https://yandex.com/support/direct/strategies/average-cpa.html) in the Help for Yandex Direct.  
AVERAGE_CPA_PER_CAMPAIGN |  "Optimize number of conversions" with per-campaign CPA See the [description](https://yandex.com/support/direct/strategies/optimize-number-of-conversions.html) in the Help for Yandex Direct.  
AVERAGE_CPA_PER_FILTER |  "Optimize number of conversions" with per-filter CPA See the [description](https://yandex.com/support/direct/strategies/optimize-number-of-conversions.html) in the Help for Yandex Direct.  
AVERAGE_CPC |  "Optimize clicks" limited by average CPC See the [description](https://yandex.com/support/direct/strategies/average-cpc.html) in the Help for Yandex Direct.  
AVERAGE_CPC_PER_CAMPAIGN |  "Optimize number of clicks" with per-campaign CPC See the [description](https://yandex.com/support/direct/strategies/optimize-number-of-clicks.html) in the Help for Yandex Direct.  
AVERAGE_CPC_PER_FILTER |  "Optimize number of clicks" with per-filter CPC See the [description](https://yandex.com/support/direct/strategies/optimize-number-of-clicks.html) in the Help for Yandex Direct.  
AVERAGE_CPI |  "Optimize number of app installations", maintain the average CPI See the [description](https://yandex.com/support/direct/strategies/average-cpi.html) in the Help for Yandex Direct.  
AVERAGE_ROI |  "Optimize ROI" See the [description](https://yandex.com/support/direct/strategies/average-roi.html) in the Help for Yandex Direct.  
AVERAGE_CRR |  "Optimize cost revenue ratio" See the   
CP_AVERAGE_CPV |  "Maximum video views", custom period See the [description](https://yandex.com/support/direct/strategies/maximum-video-views.html) in the Help for Yandex Direct.  
CP_DECREASED_PRICE_FOR_REPEATED_IMPRESSIONS |  "Lower cost for repeat impressions", custom period See the [description](https://yandex.com/support/direct/strategies/decrease-price-for-repeat-impressions.html) in the Help for Yandex Direct.  
CP_MAXIMUM_IMPRESSIONS |  "Maximum impressions at a minimum cost", custom period See the [description](https://yandex.com/support/direct/strategies/maximize-impressions-for-lowest-price.html) in the Help for Yandex Direct.  
HIGHEST_POSITION |  "Manual bid management with optimization" See the [description](https://yandex.com/support/direct/strategies/manual-strategy.html) in the Help for Yandex Direct.  
MANUAL_CPM |  "Manual bid management" (for display campaigns) See the [description](https://yandex.com/support/direct/strategies/manual-strategy.html) in the Help for Yandex Direct.  
MAXIMUM_COVERAGE |  "Manual bid management with optimization" using separate bid management for Yandex Search and ad networks See the [description](https://yandex.com/support/direct/strategies/manual-strategy.html) in the Help for Yandex Direct.  
NETWORK_DEFAULT |  Settings for impressions in ad networks based on the settings for search  
PAY_FOR_CONVERSION |  Optimize conversions, pay per conversion (for “Text & Image Ads” and “Dynamic ads” campaigns) See the [description](https://yandex.com/support/direct/strategies/average-cpa.html) in the Help for Yandex Direct.  
PAY_FOR_CONVERSION_CRR |  "Optimize cost revenue ratio", pay per conversion See the   
PAY_FOR_CONVERSION_PER_CAMPAIGN |  "Optimize number of conversions", pay per conversion (for "Smart banners" campaigns) See the [description](https://yandex.com/support/direct/strategies/optimize-number-of-conversions.html) in the Help for Yandex Direct.  
PAY_FOR_CONVERSION_PER_FILTER |  "Optimize number of conversions", pay per conversion for each filter (for "Smart banners" campaigns) See the [description](https://yandex.com/support/direct/strategies/optimize-number-of-conversions.html) in the Help for Yandex Direct.  
PAY_FOR_INSTALL |  "Optimize conversions", pay per install See the [description](https://yandex.com/support/direct/strategies/average-cpa-mobile-apps.html#average-cpa-mobile-apps__fix-cpi) in the Help for Yandex Direct.  
SERVING_OFF |  Displays are disabled  
UNKNOWN |  Reserved for strategies that are not supported in this version of the API.  
WB_AVERAGE_CPV |  "Maximum video views", weekly See the [description](https://yandex.com/support/direct/strategies/maximum-video-views.html) in the Help for Yandex Direct.  
WB_DECREASED_PRICE_FOR_REPEATED_IMPRESSIONS |  "Lower cost for repeat impressions", weekly See the [description](https://yandex.com/support/direct/strategies/decrease-price-for-repeat-impressions.html) in the Help for Yandex Direct.  
WB_MAXIMUM_APP_INSTALLS |  "Optimize number of app installations" without specifying the average CPI See the [description](https://yandex.com/support/direct/strategies/average-cpa-mobile-apps.html) in the Help for Yandex Direct.  
WB_MAXIMUM_CLICKS |  “Optimize clicks”, limited by weekly budget See the [description](https://yandex.com/support/direct/strategies/average-cpc.html) in the Help for Yandex Direct.  
WB_MAXIMUM_CONVERSION_RATE |  "Optimize conversions" without specifying the average CPA See the [description](https://yandex.com/support/direct/strategies/weekly-budget.html) in the Help for Yandex Direct.  
WB_MAXIMUM_IMPRESSIONS |  "Maximum impressions at a minimum cost", weekly See the [description](https://yandex.com/support/direct/strategies/maximize-impressions-for-lowest-price.html) in the Help for Yandex Direct.  
WEEKLY_CLICK_PACKAGE |  "Optimize clicks", limited by click package See the [description](https://yandex.com/support/direct/strategies/weekly-package.html) in the Help for Yandex Direct.  
For information about how the set of strategies depends on the campaign type, as well as the compatibility of strategies in search results and in ad networks, see the section [Display strategies](https://yandex.com/dev/direct/doc/dg/objects/campaign-strategies.html).
