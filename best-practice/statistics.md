##  [](https://yandex.com/dev/direct/doc/en/best-practice/en/best-practice/statistics#stat)Statistics
To get statistics for an advertiser's account, use the `Reports` service. For detailed instructions about how to get a report, parameter descriptions, and examples, see the [documentation](https://yandex.com/dev/direct/doc/en/best-practice/en/best-practice/\(https:/yandex.com/dev/direct/doc/reports/reports.html\)).
For equivalents of request parameters and report fields in version 4 (Live 4) and version 5 of the API, see [Statistics](https://yandex.com/dev/direct/doc/migration/concepts/stat.html) in the migration guide.
