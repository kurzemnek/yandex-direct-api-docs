# Начать с задачи

Версия адаптации 1.0 · 12 ноября 2026.

Справочник помогает собрать своего агента Директа и выполнять конкретные задачи
по API. Исполняемый рекламный движок и доступы подключаются в отдельном проекте.

Передай агенту доступ ко всей папке и напиши, например:

> Прочитай AGENTS.md и guide/START.md. Задача: понять, какие кампании приводят
> оплаты. Проект находится в … . Wiki находится в … / её нет.

Или:

> Прочитай guide/START.md. Подготовь обоснованную спецификацию первой кампании
> по доступным данным. Создание и запуск учитывай как отдельные действия.

## Процедура первого входа

1. Установи рабочую папку, бизнес-задачу, источник знаний и имеющиеся полномочия.
   Используй уже известные ответы. Не исследуй произвольные чужие каталоги.
2. Изучи существующую Wiki и её schema. Если базы нет, согласуй её место и создай
   минимальную структуру по [правилам знаний](KNOWLEDGE.md).
3. Выбери один [маршрут](ROUTES.md). Прочитай [поправки](CURRENT.md), текущую
   карточку и точные страницы выбранных методов.
4. Найди материалы самостоятельно. Сайт заменяет отсутствующий готовый рассказ
   о продукте; закрытые условия и решения владельца требуют ответа человека.
5. Задай до трёх коротких вопросов. Для каждого укажи, какое действие ждёт ответа.
6. Выполни следующий доступный шаг. Сохрани результат, фактическую проверку,
   пробелы и продолжение в рабочем проекте.

Переход: **входы → действие → результат → проверка → квитанция → следующий шаг**.
Уже разрешённую работу продолжай самостоятельно. Команда «сделай всё сам»
сохраняет зависимые вопросы и требования приёмки.

## Продолжение и контекст

`project/NOW.md` в рабочем проекте: текущий маршрут/шаг, вопросы, решения,
ссылки на доказательства, следующие чтения. До 3 КБ, обычно не больше четырёх
следующих файлов. Квитанция хранит источники, версии, команды и пределы проверки.

> Прочитай guide/START.md. Продолжи по project/NOW.md и проверь последнюю квитанцию.

Разбиение MD ограничивает чтение, но не удаляет историю сессии. Для большого шага
используй свежий контекст, если среда это поддерживает; иначе checkpoint и штатное
продолжение. Настоящий независимый критик получает принятую версию входов отдельно
от автора; его исходный ответ сохраняется. Если независимой проверки нет, допуск
остаётся незавершённым.

## Поиск без загрузки архива целиком

```bash
python3 tools/docs.py find "Reports"
python3 tools/docs.py find "создать кампанию" --route
python3 tools/docs.py check
```

Поиск не вызывает API и не отправляет рекламные данные. Архивные капчи скрыты
по умолчанию. Сначала применяй русскую карточку, затем актуальный первоисточник;
английский архив помогает найти понятие и никогда не доказывает текущую поддержку.
