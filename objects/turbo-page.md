# Turbo page (TurboPage)
The Turbo page object (TurboPage) contains settings for a Turbo page created in Turbo Page Builder. For more information, see [Turbo pages](https://yandex.com/support/direct/efficiency/turbo-pages.html) in Yandex.Direct Help.
Turbo pages can be used in ads with the type TEXT_AD, IMAGE_AD (subtypes TEXT_IMAGE_AD and TEXT_AD_BUILDER_AD), CPC_VIDEO_AD, CPM_BANNER_AD, and sitelinks. If a Turbo page is included, the website link is optional.
##  [](https://yandex.com/dev/direct/doc/en/objects/en/objects/turbo-page#service)Services
You must use the web interface for creating and editing Turbo pages.
To get a list of Turbo pages, use the [TurboPages](https://yandex.com/dev/direct/doc/ref-v5/turbopages/turbopages.html) service and the [get](https://yandex.com/dev/direct/doc/ref-v5/turbopages/get.html) method.
Use the [Ads](https://yandex.com/dev/direct/doc/ref-v5/ads/ads.html) service for assigning a Turbo page to an ad or unassigning it from an ad. See [Ad extensions](https://yandex.com/dev/direct/doc/en/objects/en/best-practice/launch-campaign#harness).
Use the [Sitelinks](https://yandex.com/dev/direct/doc/ref-v5/sitelinks/sitelinks.html) service for assigning a Turbo page to a sitelink when creating a set of sitelinks.
To get data entered by users on Turbo pages, use the [Leads](https://yandex.com/dev/direct/doc/ref-v5/leads/leads.html) service with the [get](https://yandex.com/dev/direct/doc/ref-v5/leads/get.html) method.
