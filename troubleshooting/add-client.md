# Access to register new agency clients via the API
An agency can register new clients in the Yandex Direct interface. Access to the [AgencyClients](https://yandex.com/dev/direct/doc/ref-v5/agencyclients/agencyclients.html).[add](https://yandex.com/dev/direct/doc/ref-v5/agencyclients/add.html) method is only provided to agencies who have a large number of active clients and need to regularly register new accounts in bulk.
If you previously had access to the [CreateNewSubclient](https://yandex.com/dev/direct/doc/dg-v4/reference/CreateNewSubclient.html) method for version 4 or Live 4 of the API, you can also access the [AgencyClients](https://yandex.com/dev/direct/doc/ref-v5/agencyclients/agencyclients.html).[add](https://yandex.com/dev/direct/doc/ref-v5/agencyclients/add.html) method, and you don't need to request additional access.
To apply for access to this method, log in on Yandex using the agency username and fill in the form below.
Alert
In the **Message** section, explain why you need access to the method.
