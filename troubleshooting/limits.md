# Yandex Direct API restrictions
The Yandex Direct API is free to use, but the number and type of operations available to you depend on the applicable restrictions.
The API version 5 has the following restrictions:
  * [Access restrictions](https://yandex.com/dev/direct/doc/dg/concepts/access.html)
  * [Point limitations](https://yandex.com/dev/direct/doc/dg/concepts/units.html)


If you have more questions, contact us using the form below. Please explain your question and the situation in as much detail as possible so that we can give you a comprehensive answer.
For questions related to restrictions applying to specific Yandex Direct API methods, remember to provide the following information:
  * The username of the user making requests to the Yandex Direct API.
  * The complete JSON or XML code of the request to the API server.
  * The complete JSON or XML code of the response from the API server.
  * The exact time of the request (MSK).
